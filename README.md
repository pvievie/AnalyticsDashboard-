Analytics Dashboard

A simple and responsive Analytics Dashboard prototype built using HTML, CSS, and Vanilla JavaScript.

Link:  https://pvievie.github.io/AnalyticsDashboard-/

The dashboard displays basic user statistics and provides search and filtering features for managing user account information.

Features
📊 User statistics
Total Users
Active Users
Monthly Growth
🔍 Search users by name or email
🔽 Filter users by account status
All Status
Active
Inactive
Pending
📋 Responsive user accounts table
📱 Mobile-friendly layout
⚠️ Displays a "No users found" message when there are no matching results
⌨️ Keyboard-accessible search and filter controls
🎨 Clean and modern SaaS-style interface
Technologies Used
HTML5
CSS3
Vanilla JavaScript

No frameworks or external libraries are required.
